# Roadmap verification commands

- `policy-pack` resolves an external organization floor with repository additions. Typed temporary exceptions require separate authority and cannot weaken non-waivable gates.
- `history` verifies each receipt content digest, preserves every signal's scale and provenance, and never converts missing signals to zero.
- `incremental` selects trusted checks without executing them. Empty, unknown, ambiguous, escaping, or release scope selects the full set.
- `study` verifies exact case, oracle/scoring, model-configuration, and preregistration bytes before comparing paired arms with identical immutable model, tools, limit, and oracle pins. The first study is descriptive: failures block execution qualification, and comparative claims remain disabled.

The held-out template contains no outcomes. Real execution and raw results are required before publishing any performance claim.
