# Clean Handoff

Make the next bounded action executable from durable state.

## Required record

1. Objective, requirement contract, approved decisions, and unresolved authority.
2. Repository identity, base revision, current revision, changed-path manifest, and working-state warnings.
3. What is complete, what remains, and the next action that takes under two minutes.
4. Commands or procedures already run, their exact outcomes, and evidence locations.
5. Actor identities, context lineage, review independence, approvals, exceptions, and stop conditions.

## Guardrails

Do not describe narration as proof. Link durable evidence and state uncertainty plainly. Exclude secrets and unnecessary implementation context from independent review handoffs. A same-context continuation is continuity, not independent approval.
